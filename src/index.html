1 Carte Arduino

Autre type de carte

Branche la carte en USB. Première utilisation : clique d'abord sur « Téléverser le programme dans la carte » (une seule fois par carte). Ferme tout autre logiciel qui utilise la carte (Arduino IDE, Vittascience…). Sans carte, le programme tourne quand même en simulation.

2 Modèle Teachable Machine

Option A — modèle téléchargé (sans Internet) : dans Teachable Machine, « Exporter le modèle » → TensorFlow.js → « Télécharger ». Choisis ici le fichier .zip obtenu, ou les 3 fichiers décompressés (model.json, metadata.json, weights.bin).
